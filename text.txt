# To Deploy Project.

        2. node_modules folder
        3. uploads folder
        4. config folder

        secure: true,
        sameSite: "None"



# Go to authController files and add 2 line of code inside logout function of res.status,
        secure: true,
        sameSite: "None"

        2. Then Select all payment Successed events
        3. Click Continue and select Webhook Endpoint and click continue
        4. Enter Endpoint URL of Backend URL

# Go to db.js file from Server ( backend ) and write

    Add 2 lines of code at top of the page
            import {config} from "dotenv
            config();

    Changes below values

            1. user: process.env.DB_USER
            2. host: process.env.DB_HOST
            3. database: process.env.DB_NAME
            4. password: process.env.DB_PASSWORD
            5. port: process.env.DB_PORT

    Add this below 1 line code 
            ssl: { required: true }


Push to GitHub
